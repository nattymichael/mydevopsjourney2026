# 🚀 DevOps Project 3 - MERN Stack Cloud Application

## 📌 Overview

This project is a full-stack cloud application built and deployed on AWS. It demonstrates real-world DevOps practices including backend development, frontend integration, cloud deployment, and reverse proxy configuration.

---

## 🏗️ Architecture

Frontend (React) → Backend (Node.js/Express) → MongoDB Atlas
Deployed on AWS EC2 with Nginx as a reverse proxy.

---

## ⚙️ Tech Stack

* **Frontend:** React
* **Backend:** Node.js, Express
* **Database:** MongoDB Atlas
* **Cloud:** AWS EC2
* **Process Manager:** PM2
* **Web Server:** Nginx

---

## 🚀 Features

* Create and fetch messages
* REST API integration
* Persistent cloud database
* Reverse proxy routing with Nginx
* Production-ready backend using PM2
